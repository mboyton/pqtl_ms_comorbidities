# Underlying data

This directory contains the complete proteome-wide Mendelian randomisation results underlying the study:

**Mendelian randomisation identifies proteins with effects on multiple sclerosis and related traits**

## Files

- `proteome_wide_MR_results_multiple_sclerosis.csv` — Complete inverse-variance weighted Mendelian randomisation results for 1,150 plasma protein exposures evaluated for effects on multiple sclerosis risk.

The odds ratios represent the effect on multiple sclerosis risk per 1-SD increase in genetically predicted plasma protein level.
